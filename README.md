## 製品概要

### 背景（製品開発のきっかけ、課題等）

**デジタル機器を操作するために、私たちは必ず画面やキーボード、専用のボタンを使わなければならないのでしょうか。**

現在、PCやスマートフォンを操作するには、画面上の小さなアイコンを選択したり、キーボードの特定のキーを押したりすることが一般的です。

しかし、こうした入力方法が常に適しているとは限りません。

例えば、VRヘッドセットを装着しているとき、ライブ配信中、楽器の演奏中、電子工作や制作作業に集中しているときなど、すぐにキーボードやマウスを操作できない場面があります。

音声操作という選択肢もありますが、周囲への配慮が必要な場所、会議中、配信中、騒がしい環境などでは、声を出して操作することが難しい場合もあります。

また、視覚や運動機能に制約のある利用者にとっては、小さな操作対象を正確に選択すること自体が負担になる場合があります。

私たちは、こうした状況に対して、**利用者が入力機器に合わせるのではなく、身近な環境そのものを利用者に合わせた入力インターフェースへ変えられないか**と考えました。

そこで着目したのが、普段から私たちのすぐ近くにある「机」です。

机は広い面積を持ち、日常生活や作業中に自然と触れる家具です。

この机そのものを入力デバイスに変換できれば、新たに専用のボタンを机上に置くことなく、より自由な操作方法を実現できるのではないか。

この発想から、Daasの開発を始めました。

### 製品説明（具体的な製品の説明）

**Daas（Desk as a Service）は、机の裏側に取り付けたセンサを利用して、机そのものをプログラマブルな入力インターフェースへ変換するシステムです。**

利用者は、机の特定の場所をノックするだけで、あらかじめ割り当てたPC操作やAPIの呼び出しを実行できます。

例えば、次のような使い方を想定しています。

- 机の左上を2回叩くと、Slackへメッセージを送信する。
- 机の右上を叩くと、登録済みのWebhookを実行する。
- 別の場所を叩いて、音楽の再生・停止や録画操作を行う。
- 利用者の目的に合わせて、各領域の操作内容を変更する。

システムでは、机の裏側に設置した4個の圧電素子によって、天板を叩いた際に発生する振動を電気信号へ変換します。

取得したアナログ信号は、マイコンを通じてデジタルデータとして処理されます。

そして、各センサで観測された信号の特徴から、叩いた領域を推定します。

さらに、タップした回数などのジェスチャー情報を組み合わせることで、同じ机の異なる場所に複数の操作を割り当てることができます。

現在は机を4領域に分割し、位置とタップパターンを組み合わせた16通りの操作設定を想定しています。

PC側には、各操作に実行する機能を割り当てるWebアプリケーションを用意する構成です。

**机の表面にボタンやタッチパネルを取り付ける必要がなく、普段使っている机をそのまま操作面として利用できること**が、Daasの特徴です。

### 特長

#### 1. 普通の机が、そのまま入力デバイスになる

Daasでは、机の裏側に取り付けた圧電センサによって、天板に加えられた振動を検出します。

机の表面に専用のスイッチやタッチパネルを配置する必要はありません。

従来は入力装置として扱われていなかった机を、そのまま操作インターフェースとして利用することを目指しています。

机を軽くノックするという日常的な動作を、デジタル操作へ結びつけることで、直感的な操作体験を提供します。

#### 2. 叩く場所とジェスチャーの組み合わせで操作を切り替えられる

Daasは、単に振動の有無を検出するスイッチではありません。

複数の圧電センサから取得した振動信号を比較し、机のどの領域が叩かれたかを推定します。

さらに、連続したタップの回数などを組み合わせることで、同じ机でも異なる操作を実行できます。

現在は4領域を基本とし、位置とジェスチャーを組み合わせた操作割り当てを想定しています。

将来的には、利用者が好きな場所を登録し、その場所に自由に機能を割り当てられるインターフェースへ発展させたいと考えています。

#### 3. 安価な汎用部品で、PC操作やWebサービスと連携できる

Daasは、高価な専用入力装置を前提とせず、比較的安価で入手しやすい圧電素子やマイコンを利用する構成です。

主要部品には、4個の圧電素子とESP32-S3系マイコンを使用します。

圧電素子は振動を電気信号に変換するため、机の裏側へ設置する入力センサとして利用できます。

また、取得した情報をソフトウェア側で処理することにより、特定の家電製品の操作だけでなく、PC上の機能やWeb APIへも拡張できるよう設計しています。

低価格なハードウェアと柔軟なソフトウェアを組み合わせることで、さまざまな作業環境に適応できるシステムを目指しています。

### 解決できること

Daasは、既存の入力方法を完全に置き換えるためのものではありません。

**キーボード、マウス、スマートフォンなどを操作しづらい瞬間に、新たな入力手段を提供すること**を目指しています。

主に、以下のような利用場面を想定しています。

**VR・MR利用者**

VRヘッドセットを装着しているとき、実際のキーボードが見えにくく、特定のショートカットを操作するのが難しい場合があります。

Daasを使えば、机の決まった領域をノックするだけで、録画や音楽などの補助操作を実行できます。

**ゲーム配信者・動画制作者**

ゲームの操作や配信中の会話に集中しながら、録画、シーン切り替え、定型通知などを行う場面です。

机を入力デバイスとして利用できれば、操作のたびに別の画面や入力装置を探す必要を減らせます。

**電子工作・実験・制作作業を行う人**

工具や材料を扱っている最中に、タイマー、実験ログ、録画などを操作したくなる場面があります。

Daasは、作業机にデジタル操作を割り当てることで、作業環境に適した入力方法を提供します。

**音声操作を使いづらい人・環境**

会議中、公共の場所、配信中など、声を出したくない状況でも利用できます。

**アクセシビリティへの応用**

小さな画面や物理ボタンを操作しづらい利用者に対して、操作領域を柔軟に設定できる入力手段としての可能性を考えています。

ただし、視覚・運動機能に制約のある利用者に対する実用性は、触覚的な目印、操作方法、フィードバックなどを含めた今後のユーザー検証が必要です。

### 今後の展望

**1. PCに常駐するネイティブアプリケーションへの発展**

現在のWebアプリケーションを中心とするPoCから、将来的にはバックグラウンドで常時動作するPC用アプリケーションへの発展を目指しています。

これにより、利用者が特定のWebページを開いていなくても、机からPC操作を実行できる構成を目指します。

**2. 自由な位置登録とキャリブレーション**

机の素材や大きさ、センサの固定方法によって、振動の伝わり方は変化します。

そのため、利用者が机を数回ノックするだけで操作位置を登録できるような、簡単なキャリブレーション機能の実現を目指します。

**3. 操作対象の拡張**

SlackやWebhookなどのWebサービスだけでなく、音楽再生、動画編集、配信ソフトウェア、スマートホーム機器、開発ツールなどとの連携を検討しています。

**4. 操作の認識精度と誤動作対策の改善**

叩く強さ、机の材質、周囲の振動などによる認識性能の変化を評価し、より安定した入力を目指します。

通常の作業で生じる振動と、意図的なタップを区別する仕組みも重要な開発課題です。

**5. アクセシビリティへの発展**

触覚的な目印や音声フィードバック、操作しやすい領域の個別設定などを取り入れ、異なる身体条件や利用環境に合わせられるシステムを目指します。

### 注力したこと（こだわり等）

- **「机を叩くと、APIが叩かれる」というコンセプトの分かりやすさ。** 身近な操作とソフトウェアの機能を結びつけ、誰でも短時間で理解できる体験を目指しました。
- **既存の家具をそのまま使う設計。** 机の表面に新しいボタンを並べるのではなく、裏側のセンサだけで入力機能を追加する方式にこだわりました。
- **複数の振動センサによる位置識別。** 単純な振動の有無だけではなく、各センサが取得した振動信号の違いを利用して、操作位置を推定する構成としました。
- **アナログとデジタルを横断した開発。** 圧電素子、電子回路、ADC、マイコン、通信、PCソフトウェアを組み合わせています。
- **操作のカスタマイズ性。** 机の特定領域とジェスチャーを自由に操作へ割り当てられるよう、特定の用途に依存しない設計を目指しました。
- **低コスト化への取り組み。** 比較的安価な圧電素子と汎用マイコンを利用しました。
- **幅広い利用者への応用可能性。** VR利用者、配信者、制作作業中の利用者など、既存の入力インターフェースを使いづらい場面への応用を検討しました。

## 開発技術

### 活用した技術

#### API・データ

- **HTTP / HTTPS**：外部Webサービスとの通信
- **REST API / Webhook**：登録されたアクションの実行
- **JSON**：PC側の設定情報やAPIデータの表現
- **圧電センサの振動データ**：位置推定やタップ検出に用いる入力信号

#### フレームワーク・ライブラリ・モジュール

本プロジェクトでは、マイコン側の振動計測と、PC側の入力認識・アクション実行を分けた構成を採用しています。

- **ESP32-S3向けファームウェア**：圧電センサからのアナログ信号取得
- **ADC（Analog-to-Digital Converter）**：圧電素子の電圧信号をデジタルデータへ変換
- **Bluetooth Low Energy（BLE）**：マイコンとPC間の無線データ通信を想定
- **Webアプリケーション**：入力領域や操作内容の設定・表示

使用した個別のフレームワーク・ライブラリについては、各実装のソースコードと依存関係に合わせて追記します。

#### デバイス

| デバイス | 製品・型番 | 用途 |
|---|---|---|
| マイコン | Seeed Studio XIAO ESP32S3 | アナログ信号の取得、データ処理、通信 |
| 圧電素子 | 村田製作所 7BB-27-4L0 ×4 | 机の振動を電気信号へ変換 |
| オペアンプ | NJU7043D | 圧電信号のアナログ入力回路 |
| 抵抗・コンデンサ等 | 汎用電子部品 | 入力保護、バイアス、フィルタリング |
| PC | Windows PC | 位置・ジェスチャー判定、Webアプリ、API実行 |
| 設置対象 | 木製机など | 物理的な入力面 |

### システムの構成

Daasでは、次のような処理の流れを想定しています。

```text
机を叩く
    ↓
机の天板に振動が伝わる
    ↓
4個の圧電素子が振動を電圧へ変換
    ↓
アナログ入力回路
    ↓
XIAO ESP32S3でADC取得
    ↓
PC側で位置・タップ回数を判定
    ↓
登録された操作を特定
    ↓
PC操作・API呼び出し
```

### 独自技術

#### ハッカソンで開発した独自機能・技術

**1. 複数の圧電センサによる机上の位置識別**

机の裏に設置した4個の圧電センサから振動信号を取得し、その特徴の違いによって打撃領域を推定する仕組みです。

単に振動を検知するだけではなく、複数のセンサを組み合わせて入力位置を識別することで、机の異なる領域を操作に利用することを目指しました。

関連コード：

[firmware/xiao-stream](https://github.com/jphacks/tkb_2618/tree/main/firmware/xiao-stream)

**2. 位置とタップパターンを組み合わせた入力設計**

机の領域とタップ回数などのジェスチャー情報を組み合わせて、異なる操作を表現します。

これにより、専用ボタンを追加せず、限られたセンサ数から複数の操作を実現する入力方式を設計しました。

**3. 物理入力からAPI実行までの統合**

圧電センサで取得した情報を、PC上のアプリケーションや外部サービスの操作へ結びつけます。

ハードウェアを特定の機能専用のスイッチとするのではなく、ソフトウェア側で操作内容を変更可能な構成を目指しています。

**4. 既存家具を入力デバイスへ変えるプロダクト設計**

机の表側にタッチパネルや専用ボタンを設置せず、裏側のセンサを利用することで、普段の家具の使い方を維持しながら新しい機能を追加する設計です。

このように、圧電センシング、入力認識、API実行を一体化し、日常の物理空間をソフトウェアから扱えるようにすることを目指しました。
