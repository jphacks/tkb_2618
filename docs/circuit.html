DeskAPI 入力回路

圧電サウンダー 7BB-27-4L0 ×4 の信号を、XIAO ESP32S3 の ADC で安全に読むための回路です。1チャンネルは「電流制限 → 中点バイアス → クランプ → ローパス → バッファ」の順に通り、同じものを4組つくります。オペアンプは NJU7043D（2回路入り）を2個使います。

部品値は未検証。通電前にチームで見直す（knowledge §1.2）

ダイオードについて。1N4148 などのシリコンダイオードは順方向電圧が約0.7Vあり、X が約4.0Vまで上がってオペアンプの入力定格を大きく超えるので使わない。1N5819 などの電源用ショットキーも、漏れ電流が大きく、1MΩ のバイアスがずれるので避ける。手持ちの型番が分かれば、使えるか確認する。

組んだあとの確認（受入試験 T-01・T-02）

  1. 通電前：テスターで、3V3 と GND の間が短絡していないこと。各ICの8番が 3V3、4番が GND につながっていること。
  2. 通電して、ピエゾはまだつながない：各chの X と、ADC ピン（D0・D1・D3・D4）が約1.65Vであること。
  3. ピエゾをつないで指で軽くたたく：ADC ピンの電圧が 1.65V を中心に振れること（テスターでは追えないので、ファームの生波形モードで見る）。
  4. 4つのセンサーの近くを順にたたく：たたいた近くのchが最大になること（T-02）。隣のchにも同じ形の波形が出るなら、配線の引き回しを見直す。
  5. 信号が小さすぎるとき：同じ NJU7043D で増幅に変える（−入力から GND へ抵抗、出力から −入力へ抵抗を足す）。値は実測してから決める。
