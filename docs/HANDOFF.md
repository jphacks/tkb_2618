## デザインで決まったこと（ユーザーの好み）

- 方向性は **フラットなミニマル（案 B 机マップ）**。影・グラデーション・木目やマットなどの質感は入れない。「AI slop」と言われた装飾的な案、ガラス案は不採用
- 文字は、アイコンだけでは分からないところにだけ付ける。例: アクション種別の選択肢には短いラベルを付けるが、割り当て後のキーには付けない。プロファイル名は文字。説明文・常識的な文言は書かない
- キーは Stream Deck アプリ風に、左上と右下に L 字の角の線（アイコン色、不透明度 60%）
- 机マップの上端に強弱の点（小 = 弱、大 = 強）、左端に回数の点（1 個 / 2 個）。文字ラベルは消したが点は残す
- キーの色はユーザー指定のパレット（Adobe Color）: 赤 #D62413、黄 #D6B813、緑 #13D66A、青 #2214D6、紺 #3C3781。黄と緑の上ではアイコンを黒 #121212 にする
- 背景 #121212、右パネル #1A1A1A
- 設定画面が開いているときは、叩かれたキーを光らせる。閉じているときは Windows 通知
- ドラッグでキーの入れ替えとアクションの割り当て
- メイン UI にシミュレータは入れない。開発者用のデバッグ / ログツールはあとで別画面として作る
- キャリブレーション画面のガラス風装飾はユーザーが「まだ」と保留
