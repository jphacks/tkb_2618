# 14 叩き以外の動作を増やし、それだけを撮るセッションを作る

> **構想（未着手）**。ユーザー判断で後回し（2026-10-25）。実機で 13 の 5 分のセッションを撮り、誤検出が問題になってから着手する。

`tools/tap-collect/` だけ。`app/` と `firmware/` には触らない。

## 背景

デモの机では、ノート PC を置く・マウスを使う・物を置くなど、叩いていないのに反応しそうな動作が起きる。いまの「叩き以外」は 4 種類（`rest` / `typing` / `place` / `lean`）だけで、誤検出を調べるには足りない。

- 種類を増やす。チームで思いついたものを、コードを変えずに足せるようにする
- 5 分のセッションに全部入れると長くなるので、**叩き以外だけを撮るセッション**を作れるようにする。採点はふつうのセッションのキャリブレーションを使う（`--calibrate A --test B`）

## 種類

| id | 指示 | 長さ |
|---|---|---|
| `rest` | 何もしない | 3 秒 |
| `typing` | キーボードを普通に打つ | 3 秒 |
| `place` | 机にスマホ・コップを置く | 3 秒 |
| `lean` | 机に腕・肘をつく | 3 秒 |
| `laptop` | ノート PC を机に置く（持ち上げて、置く） | 4 秒 |
| `laptop_type` | ノート PC のキーボードを打つ | 3 秒 |
| `mouse` | マウスを動かしてクリックする | 3 秒 |
| `pen` | ペンを机に置く・転がす | 3 秒 |
| `book` | 本・ノートを置く、閉じる | 3 秒 |
| `slide` | 物を机の上で滑らせる | 3 秒 |
| `bump` | 膝・椅子を机に軽く当てる | 3 秒 |

- ふつうのセッション（13 の 5 分のもの）に入るのは、いまと同じ `rest` / `typing` / `place` / `lean` の 4 つ（時間を延ばさないため）
- `--extras <id,…>` で、ふつうのセッションに入れる種類を選べる（`--no-extra` はいまどおり）
- 自分で足す: `--add-extra "monitor=モニターの向きを変える"` で `id=指示` を足せる（何個でも。長さは 3 秒）。`session.json` に指示文ごと残す。既定の id と重なったらエラー

## 叩き以外だけのセッション

```
node collect.mjs --port COM5 --disturbances            # 全 11 種類 × 2 回
node collect.mjs --port COM5 --disturbances --extras laptop,mouse --reps 3
```

- キャリブレーションの部も使用の部の叩きも撮らず、先頭の「静止」（基準値・ノイズの確認用）と叩き以外だけをシャッフルして撮る
- `--reps` の既定は 2。全種類 × 2 回で約 2 分半
- `session.json` に `mode: "disturbances"` を残す。進め方・キー・表示はいまと同じ
- `--mock` では、`laptop` はゆっくりした大きなずれのあとに置いた瞬間の小さな衝撃、`mouse` / `laptop_type` は `typing` に近い小さな振動、`pen` / `book` は小さな衝撃が数回、`slide` は細かい振動が続く、`bump` は叩きに近い衝撃が 1 回（誤検出されて当然のもの）。本物らしさは要らない

## 採点

- `--test` に叩き以外だけのセッションを渡せる（`--calibrate` は必須。`--session` に渡したらキャリブレーションの部がない旨のエラー）
- `score.md` の「叩き以外」の表は、出てきた種類をすべて並べる（`--add-extra` の種類も指示文付きで）。種類ごとに、試行の数・誤検出の数・誤検出が出た試行の割合
- 叩きの試行がないセッションだけなら、完全一致などの表は「叩きの試行なし」とし、1 行目は「叩き以外の誤検出 n 回（n 試行）」にする

## テスト

- 並び: `--disturbances` で静止＋全 11 種類 × 2 回、`--extras` と `--add-extra` が効く、id の重なりでエラー
- `--mock --disturbances` 相当のセッションを `--calibrate`（13 の `--mock` 相当のセッション）で採点し、種類ごとの表が出る
