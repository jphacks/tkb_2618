# 06 XIAO ESP32S3 とオペアンプ入力回路への対応

> **注意（PM）**: この書の部品表と「入力回路」の節は PM の誤り。正しい回路は `docs/circuit.html`（チームの回路図）と 08。ピンも D0 / D1 / D3 / D4（GPIO1 / 2 / 4 / 5）が正しい。

`app/` には触らない。`firmware/` だけ。

## 背景

実際に買うハードが決まった（秋月電子）。04 の前提（ESP32-DevKitC + 受動部品だけの保護回路）と違う。

| 部品 | 型番 | 数 |
|---|---|---|
| マイコン | Seeed Studio XIAO ESP32S3 | 1 |
| ピエゾ | 村田製作所 7BB-27-4L0（φ27 mm、リード線付き） | 4（+予備 4） |
| オペアンプ | NJU7043D（2 回路、CMOS レールツーレール、3.3 V 動作） | 2（+予備 2） |
| ダイオード | 1N5819（ショットキー） | 8 |
| 抵抗 | 100 kΩ / 1 MΩ / 10 kΩ / 1 kΩ | 各 100 本入り |
| コンデンサ | 0.1 µF / 10 µF / 0.01 µF | |

## やること

1. `platformio.ini` に `env:xiao_esp32s3` を足し、`default_envs` にする
   - `board = seeed_xiao_esp32s3`（ダウンロード済みの espressif32@6.12.0 に定義がある）
   - XIAO は USB-UART チップがなく、ESP32-S3 内蔵の USB（USB Serial/JTAG）で PC とつながる。`Serial` がその USB に出るよう `-D ARDUINO_USB_MODE=1 -D ARDUINO_USB_CDC_ON_BOOT=1` を付ける
   - ピンは今の S3 と同じ GPIO1〜4（XIAO のシルク D0〜D3 / A0〜A3）。ch0 左上 = D0 … ch3 右下 = D3
   - `esp32dev` と `esp32s3` の env は残す
2. USB CDC では、PC がポートを開いてもボードがリセットされない（起動時の `hello` を PC が見逃す）。PC は接続時に `ping` を送るので、`ping` に `hello` を返す今の動きで足りるかを確認する。PC 側がポートを開いていないときに `Serial` の送信で判定タスクが止まらないこと（送信はループ側・キューが満杯なら捨てる、の今の設計で足りるか）を確認し、足りなければ直す
3. 入力回路はバイアス付きのバッファにする。無信号時の ADC 値は 0 付近ではなく **約 2048（1.65 V）** になる。今の DC 除去（静穏時 EMA）と絶対値での判定で問題ないことを、DC 2048 を中心に正負に振れる入力の native テストで確かめる（既定の閾値 150 / strongMin 700 のままでよいかも書く）
4. `firmware/README.md` を XIAO 前提に書き直す。DevKitC / S3-DevKitC の情報は「ほかのボード」として短く残す
   - 部品表（上の表）
   - 1 ch 分の回路図（下）と、4 ch 分の部品数
   - XIAO のピン配置（D0〜D3、3V3、GND）と NJU7043D のピン配置（DIP8: 1 OUT A / 2 IN− A / 3 IN+ A / 4 V− / 5 IN+ B / 6 IN− B / 7 OUT B / 8 V+）
   - 書き込み: XIAO は `pio run -e xiao_esp32s3 -t upload`。書き込めないときは BOOT（B）ボタンを押しながら USB を挿す
   - 動作確認の手順は今の内容を XIAO に合わせる
   - Linux 検証環境のパス（`/home/tsuch/...`）は README から消す

## 入力回路（1 ch 分、PM が決めた）

```text
                3V3
                 │
               [100k]
                 │
   VBIAS ●───────┼──────────────┬──────────── （4 ch で共用）
                 │              │
               [100k]        [10µF] ＋ [0.1µF]
                 │              │
                GND            GND

   VBIAS ●──┬──────────┐
            │          │
         ピエゾ       [1M]
            │          │
   IN  ●────┴──────────┘
            │
          [10k]
            │
   NODE ●───┬───── NJU7043 IN+ （ボルテージフォロワ：OUT と IN− を直結）
            │
     1N5819 ├─▶├─ 3V3   （アノード NODE、カソード 3V3）
     1N5819 ├─◀┤─ GND   （カソード NODE、アノード GND）

   NJU7043 OUT ──[1k]──┬── XIAO Dn（ADC）
                       │
                    [0.01µF]
                       │
                      GND

   NJU7043 V+ = 3V3、V− = GND、V+–V− 間に 0.1µF をできるだけ近く（IC 1 個につき 1 個）
```

- バイアス 1.65 V（100k + 100k の分圧、10 µF で安定化）を 4 ch で共用。ピエゾの片側をバイアスにつなぐので、叩くと 1.65 V を中心に正負に振れる
- 1 MΩ はピエゾと並列（DC をバイアスに固定し、電荷を逃がす）
- 10 kΩ と 1N5819 で、強く叩いたときの高電圧を電源レールに逃がしてオペアンプ入力を守る
- 1 kΩ + 0.01 µF は ADC 手前の RC（fc ≈ 16 kHz）。ADC のサンプリング容量をオペアンプで駆動する
- 1N5819 は漏れ電流が大きめ（常温で数 µA〜）。1 MΩ に対して DC がずれる可能性があるので、README に「無信号時の出力が 1.45〜1.85 V に収まっているか確かめる」と書く（回路は変えない・部品は買い足さない）
