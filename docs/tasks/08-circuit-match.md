# 08 ファームウェアを正式な入力回路に合わせる

`firmware/` だけ。`app/` には触らない。

## 背景

チームの入力回路の正は **[DeskAPI 入力回路](https://claude.ai/artifact/SdUvAXonEdvWRYHbBbfajF)**（2026-10-24）。**回路は変えない**（ユーザー決定。部品も買い足さない）。06 で README に書いた回路（共用 VBIAS・出力側 1 kΩ + 0.01 µF・1N5819 など）は PM の誤りで、この回路図と違う。

回路図の要点（1 ch 分、4 組）:

- ピエゾ（7BB-27-4L0、約 20 nF）の片側は GND、もう片側は R1 10 kΩ を通って節点 X へ
- X: R2 1 MΩ で 3V3 へ、R3 1 MΩ で GND へ（1.65 V の中点バイアス、ch ごと）。D1（3V3 → X）、D2（GND → X）の小信号ショットキーでクランプ。C1 10 nF で GND へ（R1 と組んで約 1.6 kHz のローパス）
- X → R4 10 kΩ → NJU7043D の +IN。ボルテージフォロワ（出力を −IN に直結）。出力は ADC ピンに直結
- IC1 A（3/2/1 番）= 左上 → D0（GPIO1）、IC1 B（5/6/7 番）= 右上 → D1（GPIO2）、IC2 A = 左下 → D3（GPIO4）、IC2 B = 右下 → D4（GPIO5）。**D2（GPIO3）はストラッピングピンなので使わない**
- 各 IC の 8 番 = 3V3、4 番 = GND、8–4 番間に 0.1 µF
- ADC は減衰 12 dB で約 0〜3.1 V。中点 1.65 V なので振れ幅は約 ±1.4 V。超えた分は飽和として棄却（FW-007）
- 受入試験 T-01 で「ファームの生波形モード」で 1.65 V を中心に振れることを見る

## やること

仕様は `docs/protocol.md`（`raw` モード、`sat`、ピンの対応を追記済み）。

1. ピン: `xiao_esp32s3` env のピンを GPIO 1 / 2 / 4 / 5 にする。`esp32s3`（DevKitC-1）と `esp32dev` は今のまま。ボードごとの切り替えは `platformio.ini` の `build_flags`（例 `-D DESKAPI_PINS=...` や `-D DESKAPI_BOARD_XIAO`）で、`main.cpp` の `CONFIG_IDF_TARGET_*` だけに頼らない
2. `mode: "raw"`: `tap`・`hit` を出さず、10 ms ごとに各 ch の ADC 生値の min / max を `raw` で送る。サンプリングは今のタスクのまま、min / max の集計もサンプリング側、JSON 化と送信はループ側。NVS には保存しない。`ack` を返す
3. 飽和: 15 ms 窓のあいだに、どれかの ch の DC 除去後の絶対値が 1800 以上なら `hit` / `tap` に `"sat":true`。しきい値は定数 1 か所にまとめる
4. native テスト: 飽和の判定（1799 / 1800 の境界）、`raw` の min / max 集計、`mode raw` の受け付けと `run` への復帰、ピンの対応（XIAO で 1/2/4/5）
5. `firmware/README.md` を回路図どおりに書き直す
   - 回路の正は上のリンクだと明記し、1 ch 分の回路と全体の配線（IC のピン・XIAO のピン）を回路図どおりに写す。06 の誤った回路（共用 VBIAS、1 kΩ + 0.01 µF、1N5819 を使う記述、オペアンプで増幅する記述）を消す
   - 部品表は回路図の BOM どおり（NJU7043D ×2、10 kΩ ×8、1 MΩ ×8（4 ch でそろった値）、小信号ショットキー ×8（BAT43 / BAT85 / BAT54 など、BAT54S なら ×4）、10 nF ×4、0.1 µF ×2、7BB-27-4L0 ×4）。回路図の注意（1N4148 や 1N5819 は使わない）も写す
   - 受入試験 T-01 / T-02 を回路図どおりに書き、T-01 の「生波形モード」は `{"t":"mode","mode":"raw"}` を送って `pio device monitor` で `raw` の min / max を見る手順にする（無信号で 2048 付近、叩くと幅が広がる、確認後は `{"t":"mode","mode":"run"}`）
   - ピエゾの貼り方（任意のテーブル向け）: 作業する範囲の 4 象限の中心あたりの天板の裏に、4 個とも同じ方法で貼る。脚・フレーム・天板のつなぎ目の真上は避ける。金属のテーブルでは、ピエゾの金属面が天板に触れないよう絶縁テープを 1 枚はさむ

## 完了条件

- `pio run -e xiao_esp32s3`、`pio run -e esp32dev -e esp32s3`、`pio test -e native` が通る
- README の回路・ピン・部品表が回路図と一致している
- 報告に、実機で確かめるべき項目を列挙する
